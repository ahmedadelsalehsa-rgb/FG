# Source Guides

Put your guides here, **one folder per chapter id**, for example `sources/B6/` for Change Management & CAB. Any format works: `.md`, `.docx`, `.pdf`, `.pptx`, `.xlsx`, or a `links.md` with URLs.

When you send guides, it helps to say for each one:
- which chapter(s) it belongs to (one guide can feed several)
- whether it is **mandatory company content** (copy the rules exactly) or **reference material** (summarise and adapt)
- whether it is confidential. If it is, keep it out of this repo and paste only the parts that can be used.
