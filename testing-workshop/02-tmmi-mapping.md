## Generic practices: what to stress

TMMi also expects Generic Goals (GG2 "Institutionalize a managed process" and, from Level 3, GG3 "Institutionalize a defined process"). The workshop addresses them implicitly:

| Generic practice | Where trainees see it |
|---|---|
| GP2.2 Plan the process | MTP and Test Plan (M6) |
| GP2.5 Train people | This workshop itself |
| GP2.6 Manage configurations | Change Management, baselines (M3, M9) |
| GP2.8 Monitor and control the process | KPIs, gates (M7) |
| GP2.9 Objectively evaluate adherence | Gate checklists, QA audit in capstone |
| GP2.10 Review status with higher-level management | Gate reviews, breach escalation |
| GP3.1 Establish a defined process | Standard process + tailoring (M2) |
| GP3.2 Collect improvement information | KPI history, CAPA, lessons learned |

> Verify the SP titles against the TMMi Framework release your organisation is assessed against. The structure above follows TMMi Framework R1.3.
